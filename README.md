# ともかクエスト

小学生高学年向けの、PC/iPadブラウザで遊べる剣と魔法の2DアクションRPGです。

## 遊び方

静的ファイルだけで動作します。ローカル確認する場合は、リポジトリ直下で簡易サーバーを起動してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開くとプレイできます。

## 操作

- PC
  - 移動: WASD / 矢印キー
  - 攻撃: Space / クリック
  - 魔法: Q
- iPad / タッチ端末
  - 左スティック: 移動
  - 右下ボタン: 攻撃 / 魔法

## 実装内容

- タイトル画面、主人公選択、クリア画面
- `assets/asset-library.jpg` を、提出されたアセットライブラリ画像として主人公・敵・ボス・一部エフェクトにそのまま使用
- イケメン剣士、銀髪剣士、かわいい女子魔法剣士、闇落ち女子、ダークヒーロー、少年冒険者、弓使いなど9人の主人公
- アセット画像が未配置の場合のみ、内部描画の仮スプライトにフォールバック
- 草の密度、土道、水辺、花、樹木、崖、ミニマップ風表示を含むRPGフィールド
- パーティメンバーの顔・HP/MPが並ぶRPG風HUD
- 振りかぶり、踏み込み、振り抜き、斬撃軌跡を含むアクションゲーム寄りの武器攻撃
- 派手な剣・魔法・ボス演出
- 森、草原、火山、湖、砂漠、闇の城の6ステージ構成と大型ボス
- 豊富な通常敵、レアモンスター「キラキラスライム」
- ステージ終了時だけ出る小学2年生向けの算数・国語クイズ
- 落下死なし、敗北時も即再挑戦できる低ストレス設計
- Web Audio APIによるRPG風の多層BGMと効果音
- localStorageによる続きからプレイ
