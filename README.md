# ともかクエスト

小学生高学年向けの、PC/iPadブラウザで遊べる剣と魔法の2DアクションRPGです。

## 遊び方

静的ファイルだけで動作します。ローカル確認する場合は、リポジトリ直下で簡易サーバーを起動してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開くとプレイできます。

## 操作

- PC
  - 移動: WASD / 矢印キー
  - 攻撃: Space / クリック
  - 魔法: Q
- iPad / タッチ端末
  - 左スティック: 移動
  - 右下ボタン: 攻撃 / 魔法

## 実装内容

- タイトル画面、主人公選択、クリア画面
- イケメン、かわいい女子、闇落ち女子、ダークヒーローなど6人の主人公
- 派手な剣・魔法・ボス演出
- 5ステージ構成と大型ボス
- 豊富な通常敵、レアモンスター「キラキラスライム」
- 小学2年生向けの算数・国語クイズ
- 落下死なし、敗北時も即再挑戦できる低ストレス設計
- Web Audio APIによるBGMと効果音
- localStorageによる続きからプレイ
